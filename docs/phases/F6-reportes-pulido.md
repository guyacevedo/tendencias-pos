# F6 — Reportes y pulido

## 6.1 Reportes
Ventas por rango de fechas, por producto/talla, por cajero; cuentas por cobrar (antigüedad) y por pagar;
existencias valorizadas. Consultas de solo lectura con proyecciones; exportar a Excel (Apache POI) desde
el escritorio. **Aceptación:** cada reporte con prueba de su consulta.

## 6.2 Tablero, auditoría y portafolio
Tablero de inicio (ventas del día, cobros, saldo de caja, bajo mínimo, gráfica 30 días); visor de
auditoría (ADMIN); manual de usuario; README con capturas, GIF del flujo de venta y diagrama; etiqueta
`v1.0.0`. **Aceptación:** release 1.0 publicado.
