# F7 — Facturación electrónica DIAN (posterior)

Puerto `billing.ElectronicInvoiceProvider` ya definido desde 3.2. Implementar un adaptador para el
proveedor tecnológico elegido (p. ej. API de Factus), con envío asíncrono, reintentos, almacenamiento de
CUFE, XML y PDF, y pruebas en el ambiente de habilitación. Requiere resolución de facturación electrónica
del cliente.
