# Especificaciones por sesión

Cada sesión es una conversación nueva: leer `CLAUDE.md`, `docs/STATE.md` y solo la sección de la
sesión. Una sesión termina cuando se cumplen sus criterios, `tpos_build` pasa, `STATE.md` está
actualizado y hay commit. Si algo no cabe, se anota en `STATE.md` y pasa a la sesión siguiente.
